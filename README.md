# GameLauncher

A minimal TUI game launcher for Linux.

## Features

- Steam games detection
- Dolphin GameCube/Wii support
- Keyboard focused
- Built with Bash and fzf
- Lightweight

## Requirements

- Bash
- fzf
- Steam
- Dolphin (optional)

## Install

Clone the repository:

```bash
git clone https://github.com/USERNAME/gamelauncher.git
